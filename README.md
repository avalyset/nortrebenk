# nortrebenk

nortrebenk måler hvor godt og raskt kodeagenter løser oppgaver fra offentlig kode i norske etater, og hva hver løste oppgave koster. Oppgavene er mergede pull requests fra etatenes offentlige GitHub-repoer, og fasiten er etatens egne tester: en oppgave regnes som løst når testene som feilet før endringen, passerer, og de som passerte, fortsatt passerer.

**Status: under utvikling, ikke publisert.**

## Grenser (NTB-0001)

v1.0 skal være et oppgavesett, en gjentakbar metode og en forhåndsregistrert pilotmåling. Det er ikke en rangering av agenter, ikke et bilde av etatenes kode, ikke et mål på lisensverdi, ikke en måling av menneske med agent og ikke en måling av GitHub Copilot.
